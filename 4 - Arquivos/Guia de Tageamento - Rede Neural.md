# Guia de Tageamento - Rede Neural (PARA + Zettelkasten)

Para o Obsidian funcionar como um "segundo cérebro" e desenhar uma Graph View (Rede Neural) rica e organizada, o uso adequado de tags e links é essencial. 

## 1. Tipos de Tags em Cascata
Para evitar centenas de tags confusas, usamos a estrutura em cascata `tipo/macro/tema`.

As principais raízes de contexto são:
- `#tipo/trabalho/...`
- `#tipo/estudo/...`
- `#tipo/recurso/...`
- `#tipo/projeto/...`
- `#tipo/diario`
- `#tipo/geral`

**Exemplos Práticos:**
Se você for começar uma nova anotação de estudos sobre Inteligência Artificial, a tag seria:
`#tipo/estudo/ia`

Se for uma ata de reunião do projeto X no trabalho:
`#tipo/trabalho/projeto_x`

*O robô de automação do seu cofre já configurou as suas anotações atuais seguindo essa taxonomia baseada nas pastas onde seus arquivos se encontravam.*

## 2. Como usar no dia a dia
- Toda nota que você cria deve ter uma tag hierárquica `tipo/...`.
- Na seção `properties` (Frontmatter) no topo da página, insira suas tags para manter a nota limpa.
- **Dica de Ouro:** Não use a tag no lugar de um link. Se uma entidade é importante (ex: uma pessoa, um cliente, um projeto grande), crie uma nota para ela e faça um *Link* `[[Nome do Cliente]]` em vez de usar tag. Links criam a rede neural muito mais forte!

## 3. Cores no Graph View
Abra o **Graph View** (Grafo) e clique na engrenagem. Vá em **Grupos (Groups)** e atribua cores para as tags raízes que você criou:
- Ex: `#tipo/trabalho` -> Azul
- Ex: `#tipo/estudo` -> Verde
- Ex: `#tipo/diario` -> Cinza

Isso fará o seu cofre florescer visualmente!
