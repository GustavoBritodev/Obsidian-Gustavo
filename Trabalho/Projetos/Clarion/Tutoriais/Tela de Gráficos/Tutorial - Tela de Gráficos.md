## 🎯 Objetivo
O módulo de "Gráficos" é o motor analítico da plataforma. O Clarion é uma solução que leva você do dado à decisão com autonomia: transforme dados em visões claras e dashboards interativos, sem depender de analistas dedicados ou licenças de BI tradicionais. Este é o ambiente onde os componentes individuais dos dashboards são forjados.

## 🔍 Onde Acessar
Acesse a tela através do menu superior do sistema, clicando em **"Gráficos"**.

## 💻 Detalhamento da tela
Ao acessar o módulo, o usuário é direcionado para a listagem principal, que atua como uma biblioteca de todos os gráficos criados no seu ambiente.

> 📸 ![[Tela de Gráficos - Com Gráficos.png]]

Na tela inicial, as seguintes informações e recursos são apresentados:

* **Barra de Busca:** Localize rapidamente gráficos específicos pelo nome.
* **Listagem de Gráficos:** Exibe cards detalhados contendo o nome do gráfico, o tipo visual (ex: Barra, Pizza), o nome da fonte de dados associada, a data da última atualização e o autor.
* **Visibilidade (Tag Público/Restrito):** Indica quem tem acesso àquele gráfico. 
	* **Público:** O gráfico fica visível e disponível para **todos** os usuários que possuem acesso àquele ambiente/cliente. 
	* **Restrito:** O gráfico fica visível **única e exclusivamente para o usuário que o criou** (autor).

## 🔒 Segurança dos Dados
A plataforma utiliza criptografia de ponta a ponta e segue os padrões de segurança da Microsoft para integrações na nuvem. Os dados processados no Clarion nunca são compartilhados com terceiros.
