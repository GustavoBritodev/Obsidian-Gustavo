Agent = Model + Harness
Model = LLM (GPT5, Claude Opus 4.8 e etc)
Harness = Todo o resto em volta (instruções, estruturas do repo, linters, testes, arquivos de progresso, scrips de setup) basicamente é o ambiente operacional que envolve o modelo.
![[Harness Engineering.png]]

Spec Driven Development é um tipo de Harness Engineering, ele ajuda a criar funcionalidades inteiras, mas não sistemas inteiros.
