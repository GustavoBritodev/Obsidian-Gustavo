


- Uma variável deve ser clara, sem abreviações ou definição sem sentido;
- Uma variável é sempre no singular, exceto quando se referir a um array ou uma coleção;
- Defina um idioma único para suas variáveis. Se declarar uma em inglês então declare todas as outras em inglês também;


## Métodos

Os métodos deverão ser nomeados como verbos, através de uma mistura de letras maiúsculas e minúsculas. Em princípio todas as letras que compõem o nome devem ser mantidas em minúsculo, com exceção da primeira letra de cada palavra composta a partir da segunda palavra. 

Exemplos sugeridos para nomenclatura de métodos:

```
somar (int n1, int n2){}

abrirConexao(){}

concluirProcessamento(){}

findById(){} //Normal encontrar métodos em inglês

calcularImprimir(){} // Há algo errado nesse método, visto que ele deveria ter uma única finalidade
```
