De inicio o projeto da Sun MicroSystems chamado Green resultou no desenvolvimento de uma linguagem baseada em C e C++, que o criador James Gosling nomeou de Oak (carvalho), em homenagem a uma árvore que tinha em frente ao escritório dele na Sun. 

Tempos depois descobriram que já havia uma linguagem chamada Oak, então um dia a equipe da Sun visitou uma cafeteria local o nome Java que é a cidade de origem de um tipo de café importado foi sugerido e o nome pegou.

Atualmente o Java é da Oracle
