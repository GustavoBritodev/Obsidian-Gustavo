# Skills
Pacotes de instruções especializadas que a IA carrega sob demanda

Estrutura:
SKILL.md -> instruções
scripts/ -> python/bash executável
resources/ -> Templates/docs

* Só ativa quando faz sentido
* Não consome contexto atoa
* Pode executar código real

Sem Skills
* Respostas genéricas
* Código de tutorial
* Sem padrões profissionais
* Contexto desperdiçado
Com Skills
* Especialista sob demanda
* Código de produção
* Padrões OWASP, React e etc
* Contexto otimizado

Comando no terminal para instalar o awesome skills:
npx antigravity-awesome-skills

## Aba Customizações:
# Rules

Regras que podem ser adicionadas globalmente (todos os os projetos) ou somente no workspace (projeto) desejado

# Workflows

Prompts que posso deixar salvo para o agente seguir
Exemplo: Criar um workflow para arquitetura de diretórios de projetos, e ao criar um novo projeto chamar esse worklflow com o /nome do workflow que ele vai ser acionado e criar a estrutura de diretórios.

## Aba Servidores MCP
Linguagem Universal das ferramentas, usado para comunicação de outras ferramentas/plataformas para se conectar com LLMs.
