BigO:
* Fala sobre escalabilidade do algoritmo com base no tamanho do input, não necessariamente sobre performance

Complexidade Temporal:
* Diz respeito ao tempo de execução do algoritmo (Runtime)
Complexidade Espacial:
* Diz respeito ao quanto de memória adicional precisamos alocar

O(1) -> tempo constante ou memória constante, ou seja, independente do tamanho do input o algoritmo tem o mesmo tempo de execução


O (log n) -> Conforme o input aumenta, o tempo de execução não aumenta tão rápido quianto o input (Input cresce exponencialmente, enquanto o tempo de execução cresce linearmente) Ex: Binary search

O (n) -> escala conforme o input aumenta, se o input dobra, o tempo d execução dobra também

O (n log n) -> Ex: Algoritmos de Sorting (Exceto bubblesort) e Divide and Conquer

O (n²) -> Basicamente um loop dentro de um loop. Ex: Algoritmo de bubblesort

Também existe O(raiz de n), O(2^n) e O(n!)

array -> espaço contínuo em memória
