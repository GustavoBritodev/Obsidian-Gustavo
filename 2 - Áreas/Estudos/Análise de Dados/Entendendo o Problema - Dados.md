Refinando uma pergunta:
1. Especificar o objetivo -> O que exatamente queremos descobrir?
2. Definir uma métrica -> Como podemos medir isso?
3. Estabelecer um recorte temporal -> Qual período devemos analisar?
4. Considerar segmentações relevantes -> Comparar por região, canal, tipo de cliente?

# Técnica S.M.A.R.T
**S (Específica):** A pergunta é clara e bem definida?
**M (Mensurável):** Podemos quantificar a resposta?
**A (Atingível):** Os dados necessários estão disponíveis?
**R (Relevante):** A resposta ajudará na tomada de decisão?
**T (Temporal):** A análise cobre um período adequado?

### **Correlação não implica causalidade**

## Perguntas de dados refinadas X não refinadas:
Não refinada: Nosso app é popular?
Refinada: Qual a taxa de retenção de usuários do nosso app nos últimos 3 meses e como ela se compara com o benchmarking do setor?

Não refinada: Nossos clientes gostam do nosso suporte?
Refinada: Qual o índice de satisfação (NPS) por canal de atendimento dos últimos 6 meses e quais são os principais motivos de reclamação?

Não refinada: Nosso e-mail marketing está trazendo clientes?
Refinada: Qual a taxa de abertura, clique e conversão das campanhas enviadas nos últimos 3 meses?

Perguntas para refinar:
1. Nossa marca tem reconhecimento no mercado?
2. O desconto que oferecemos está ajudando nas vendas?
3. Por que nossa taxa de cancelamento aumentou?
4. As redes sociais estão trazendo clientes novos?
5. Os usuários estão satisfeitos com o tempo de carregamento do nosso site?

### Matriz para Clasificação de Stakeholders:
R.A.C.I
R (Responsible) -> Responsável pela execução da tarefa
A (Accountable) -> Aprovador final, quem toma a decisão
C (Consulted) -> Consultado para dar opiniões ou expertise
I (Informed) -> Informado sobre o progresso ou resultado]

#### Como usar R.A.C.I:
1. Mapeie todas as atividades ou entregáveis do projeto
2. Defina claramente os papéis de cada pessoa ou equipe
3. Evite múltiplos "A" (Accountable) para a mesma tarefa
4. Use uma tabela para visualizar as responsabilidades

- Baixa Prioridade (Baixo esforço, Baixo impacto)
