### Amplitude:
Amplitude é a diferença entre o maior e o menor elemento do conjunto de dados obtidos na pesquisa.

### Variância e Desvio Padrão:
O Desvio Padrão mostra o quanto, em média, os valores se afastam do centro, da média.

Imagina que você é o analista de dados de uma rede de 3 lojas. O dono te chama para uma reunião e fala: "Olha, se a média de faturamento das minhas lojas estiver acima de 50%, pra mim está ótimo, tá tudo funcionando bem!"
